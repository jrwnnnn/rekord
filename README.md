Rekord is a web app that automates the generation of DepEd School Form 9 and 10 (SF9/SF10) PDFs. It turns a single CSV into a zip file of print-ready PDFs in a matter of seconds.

Parsing and PDF/ZIP generation occur entirely in the browser. Generated files are downloaded directly to your device. No student records, LRNs, names, grades, or documents are ever uploaded, transmitted, or saved to any external server.

Rekord is built with [Astro](https://astro.build) and [TypeScript](https://www.typescriptlang.org/).

> [!NOTE]  
> SF10 support is temporarily paused pending DepEd's new trimestral layouts.

## Features

- Extremely fast bulk generation of editable SF9 PDFs
- Automatic school form type detection
- DepEd-standard typography
- Option to flatten the generated PDFs
- Direct ZIP archive download
- Private by design
